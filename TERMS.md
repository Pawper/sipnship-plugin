## What that means in practice

The plugin runs commands on your machine and against your repository with your own credentials: it refuses some commands, merges pull requests when you run the merge queue, removes the worktrees of merged branches when you run the worktree script with its apply flag, and edits labels and board fields when you run the board scripts. Read what a script does before you run it, and try it on a repository you can afford to get wrong first. The dry modes exist for that.

There is no service behind the plugin, so there are no accounts, fees, uptime promises or support obligations. Help is offered on a best-effort basis through the issue tracker at https://github.com/Pawper/sipnship-plugin/bootstrap/issues.
